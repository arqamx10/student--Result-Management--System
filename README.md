# Student Result & GPA Management System

A simple Python-based student result management system.

## Features

- Add multiple students
- Calculate total marks
- Calculate percentage
- Assign grades
- Calculate GPA
- Search students
- Edit student information
- Delete students
- Save student data using JSON
- Input validation

## Technologies Used

- Python
- JSON

## How to Run

1. Download or clone this repository.
2. Open `newfile.py` in Python.
3. Run the program.
4. Follow the instructions shown in the menu.

## Project Purpose

This project was created to practice Python programming, functions, loops, lists, dictionaries, file handling, JSON data storage, and basic result management.
